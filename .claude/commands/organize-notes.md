# organize-notes

議事録・会議メモ・相談メモ・動画/ウェビナーの文字起こしを、あとで使いやすい議事録形式に整理します。

## 使い方

```
/organize-notes [--tone <経営層向け|技術者向け|一般>]
```

整理したいテキストをこのコマンドの後に貼り付けるか、事前にチャットに貼り付けてからコマンドを実行してください。

## 引数

- `--tone`: 出力のトーンを指定します（省略時は「一般」）
  - `経営層向け`: 簡潔・結論先行・数値重視
  - `技術者向け`: 詳細・専門用語保持・実装観点を含む
  - `一般`: 平易で読みやすい標準的なトーン

## 動作

以下のステップで整理します。

1. **前処理**: 話し言葉・フィラー・重複を除去し、読みやすいテキストに整える
2. **構造化**: 標準的な議事録フォーマットに変換する
3. **Q&A 抽出**: 質疑応答のやり取りを独立したセクションとして整理する
4. **トーン調整**: 指定されたトーンに合わせて文体を調整する

## 出力フォーマット

```
# 議事録 / 会議メモ

## 基本情報
- 日時: （テキストから推定、不明な場合は「要確認」）
- 参加者: （テキストから抽出）
- 種別: （会議 / 相談 / ウェビナー / 動画 など）

## 概要
（全体の目的・背景を2〜3文で）

## 議題と討議内容
### 1. [議題名]
- **議論の要点**: ...
- **結論**: ...

### 2. [議題名]
...

## Q&A
| 質問 | 回答 | 回答者 |
|------|------|--------|
| ... | ... | ... |

## 決定事項
- [ ] ...

## 次回アクション
| # | アクション | 担当者 | 期限 |
|---|-----------|--------|------|
| 1 | ... | ... | ... |

## 補足・その他メモ
...
```

## プロンプト

$ARGUMENTS に `--tone` オプションが含まれる場合はそのトーンを使用し、含まれない場合は「一般」トーンを使用してください。

以下のテキストを上記フォーマットに従って整理してください。整理にあたっては次のことを守ってください。

- 話し言葉・フィラー（「えー」「あの」「そうですね」など）は除去する
- 重複した発言は一つにまとめる
- 発言の意図を損なわずに要点を抽出する
- Q&A セクションには、質問と回答が明確に対応するもののみ記載する（曖昧なものは「議題と討議内容」に含める）
- 決定事項とアクションアイテムは必ず分けて記載する
- 日時・参加者が不明な場合は「要確認」と記載し、推測で埋めない

整理対象のテキスト:

$ARGUMENTS
